        Tesseract recorta el lateral derecho y hace OCR sobre la
        imagen binarizada. Plantillas compara cada carácter contra
        las plantillas CAD. Se aplica al enviar la siguiente captura.

        ?endpoint=https://tu-servidor/api/process y
        ?engine=tesseract.
      
    

      
    
        Servidor de ejemplo: cd ProtipoFotosWeb →
        python server.py → http://localhost:3000.
        En GitHub Pages no hay backend, así que hay que apuntar el endpoint a
        una máquina donde se ejecute.
